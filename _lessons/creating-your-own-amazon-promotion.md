This lesson will teach you how to create your own promotion. A promotion is a coupon or discount code that gives a customer a discount or an incentive to purchase your product.

![Creating your own Amazon Promotion](https://academy.lovetheidea.co.uk/wp-content/uploads/2022/02/Creating-your-own-Amazon-Promotion-300x185.png)

We'll go over this information here, however, Amazon provides a great lesson if you want additional details. Simply go to Seller Central and click the "learn more" link next to the "Manage Promotions" headline.

### **How to Set Up a Coupon Code/Promotion** 

Follow these steps to set up your coupon code

-   Log into your **Seller Central** Account 
-   At the top navigation select **Advertising** > **Manage Promotions** 
-   Under Manage Promotions you will see different types of promotions you can set up and run  
-   **Percentage Off** – This promotion enables you to provide a discount on your inventory goods to customers based on how they acquire your products.
-   **Buy One Get One** – Buy one and get one free 
-   For this course, we will focus on the **Percentage Off** promotion since this is the one you will use the most.

####  **Configuring the Percentage Off Promotion** 

-   First, you need to create a Product Selection list – a list of one or more of your products. 
-   Choose **Manage Product Selections.** 
-   Select “**Create New Product Selection**” 
-   You will see a list of options to select your product. ASIN is easiest. 
-   Click **Submit** 
-   At the new screen, you create your own Tracking ID or name of promotion and description. 
-   Enter ASIN on ASIN List 
-   Click **Submit**
-   Click the **Manage Promotion** button, which will take you to the following screen: ![](https://academy.lovetheidea.co.uk/wp-content/uploads/2022/01/Module-6-img1-300x145.png) 

As you can see, Amazon has three different sections:

#### **Step 1- Conditions** 

-   **Buyer Purchase** - Set the minimum number of goods or money amount that the customer must purchase to qualify for the promotion.
-   **Purchased Items** - Indicate which product you want this campaign to apply to - or whether you want it to apply to all of your items. (In this scenario, we're only going to set up for one product.)
-   **Buyer Gets** \- Tell Amazon how much of a discount you want. It is suggested that you utilize a dollar sum instead of a percentage off.
-   Applies to this is where you can specify the criteria for receiving the discount. You can create tiers in Advanced Options, for example, if a buyer buys 5 of the same item, they will receive a discount.

#### **Step 2 - Scheduling** 

Please take note that all promotions take 4 hours to get set up in the system.  

-   **Start and End Date** -Set the start date and time, and the end date you want your promotions to run. 
-   **Internal Description** \- this is for your purpose only 
-   **Set tracking ID** - Amazon creates a default one for you

#### **Step 3 - Additional Options** 

-   **Claim Code** - Checking the Claim Code check box tells Amazon buyers must have a claim code to get a discount. This is most likely what you will want to do. Make sure "Single-use" is checked so that no one else can use your voucher. If you choose, you can create your own Claim Code, or you can use Amazon's default.
-   **Claim Code Combinability** - check this if you want to be able to combine other promotions with this one, however, most people don't because they want this one to be exclusive.
-   **Checkout Display Text** \- Amazon has preset text, but you can alter it. This appears during the checkout process.
-   **Short Display Text** \- you can leave that blank 
-   **Terms and Conditions** \- you can leave those as they are if you want 
-   Then click **Review** 

### **Reviewing Promotion** 

-   Make sure to double-check your promotion for any problems. If everything seems good, click submit. The promotion will be listed under "Pending" in your promotions list.
-   Once your campaign is up, make sure to test it by using your Amazon buyer account or having someone else use their account to see whether it works.

-   Make sure promotion is not showing up on the product detail page 
-   Add the item to your cart 
-   Add the promotion code 
-   Check to see if the promotion is added 
-   No need to actually purchase the product, just delete it from your cart. 

To understand how to use the other promotions, go to the Seller Central Account and click the "**Learn more**" option next to Manage Promotions.
