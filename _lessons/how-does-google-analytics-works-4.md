## **The process of collecting Analytics data**

Google Analytics is a platform that gathers and analyzes data to produce useful reports.

### **Tracking a Website**

In order to track a website, you should first create a Google Analytics account. Then you need to add a small piece of Javascript tracking code to each page on your site. Whenever a user visits a web page, the tracking code collects anonymous information about how that user interacts with that page.

A tracking code on the Google Store could provide information about how many users viewed a drinkware page versus a homeware page. You can also use it to determine the number of users who purchased an item like an Android doll by tracking whether they made it to the confirmation pages of their purchase.

![Tracking a Website](https://r2.businesscrowd.co.uk/wp-content/uploads/2021/10/Google-Image-2-2-300x178.png)

A tracking code also collects information about a browser, such as a language set, the type of browser (like Chrome or Safari), and the device and operating system used to access the Google Store. It can even collect information about the "traffic source" that brought users to the site in the first place. It could be a search engine, an advertisement they clicked on, or an email marketing campaign.

Keep in mind that every time a page loads, the tracking code will collect and send updated information about the user’s activity. Google Analytics groups this activity into a period of time called a “session.” A session begins when a user navigates to a page that includes the Google Analytics tracking code. A session ends after 30 minutes of inactivity. A new session will begin if the user returns to a page after a session has ended.

### **Processing and Reporting**

When the tracking code collects data, it packages that information up and sends it to Google Analytics to be processed into reports. When Analytics processes data, it aggregates and organizes the data based on particular criteria like whether a user’s device is mobile or desktop, or which browser they’re using.

But there are also configuration settings that let you control how data is processed. Using a filter, for example, will ensure your data does not include company traffic or will only include data from a particular country or region that is important to your business.

![Processing and Reporting](https://r2.businesscrowd.co.uk/wp-content/uploads/2021/10/Google-Image-3-2-300x100.png)

Here's one thing you should remember:

**"Once Analytics processes the data, it is stored in a database where it cannot be changed."**

So remember, when setting up your configuration, don’t exclude any data you think you might want to analyze later. Once the data has been processed and stored in the database, it will appear in Google Analytics as reports.
